# Integrated Business Management and Networking Platform
## For University Student Entrepreneurs in Kenya

A Django + SQLite web application that lets Student Business Owners (SBOs) track products, sales, expenses and stock, and find and partner with other approved student businesses. No JavaScript, no CDN, no external services — plain HTML/CSS, all amounts in KES, timezone Africa/Nairobi.

---

## 1. Install on Windows (Git Bash)

### 1.1 Prerequisites

- Python 3.10+ installed and on PATH (`python --version` works in Git Bash)
- Git for Windows installed (includes Git Bash)
- VS Code installed (optional but recommended)

### 1.2 Clone or unzip the project

If you downloaded a zip, unzip it and `cd` into it. If you cloned from GitHub:

```bash
git clone https://github.com/<nanatoto-droid>/student-biz-platform.git
cd student-biz-platform
